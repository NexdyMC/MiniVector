# 🖼️ UI Layout & Design Editor Specification

Spesifikasi tata letak ruang kerja Mini Figma.

## Pembagian Area Utama

1. **Top Navigation & Toolbar (`Header`)**:
   - Tool selection: Select (V), Rectangle (R), Path/Pen Tool (P), Hand Tool (H).
   - Undo / Redo controls.
   - Zoom percentage indicator.

2. **Left Sidebar (`Layer Panel`)**:
   - Scene Tree hierarchy (Daftar objek & grup).
   - Visibility toggle (Icon mata) & Lock toggle (Icon gembok).

3. **Center Area (`Canvas / Workspace`)**:
   - Viewport tempat elemen dirender.
   - Bounding box transform handles & inner radius control dots.

4. **Right Sidebar (`Inspector Panel`)**:
   - **Transform Section**: X, Y, Width, Height, Rotation Angle.
   - **Appearance Section**: Fill color, Stroke color, Stroke width.
   - **Corner Radius Section**: Input 4 sudut individual.
